# Manager Coach IA

Versão para a Play Store do assistente de jogos de manager de futebol: lê as telas do jogo (gravação de tela do Android, com permissão do usuário), monta a tática, prevê o jogo e aprende com os resultados.

- Código Android: `app/` (Kotlin + Jetpack Compose + Room + ML Kit).
- Build: GitHub Actions gera o **AAB** (Play Store) e APKs de teste a cada push (`.github/workflows/android.yml`).
- Publicação passo a passo: **[PUBLICAR.md](PUBLICAR.md)**.
- Política de privacidade: `docs/privacy.html` (GitHub Pages).
- Textos e imagens da loja: `docs/loja/`.

App independente: não é afiliado, patrocinado nem aprovado pela Gamebasics ou pelo Online Soccer Manager.
